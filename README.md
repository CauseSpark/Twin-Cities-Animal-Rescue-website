# Twin Cities Animal Rescue Website

**A welcoming, accessible web platform connecting rescued animals with adopters, fosters, and volunteers.**

This is the public-facing website for Twin Cities Animal Rescue, a nonprofit organization dedicated to rescuing, rehabilitating, and rehoming animals across the Twin Cities metro area. The site serves as the organization's digital hub for adoptions, volunteer engagement, foster recruitment, and community connection.

## Features

### For Visitors & Potential Adopters
- **Interactive Pet Finder**: Browse all animals currently available for adoption with live filtering by species, age, and kid-friendliness
- - **Saved Shortlist**: Save favorite animals to a personal list that persists even after leaving the site (using browser storage)
  - - **Detailed Animal Profiles**: View comprehensive information about each animal including personality traits, behavioral notes, and adoption requirements
    - - **Multiple Ways to Get Involved**: Clear pathways to adopt, foster, volunteer, or partner with the organization
     
      - ### For the Organization
      - - **Mission Communication**: Clear explanation of rescue operations, care standards, and impact metrics
        - - **Impact Transparency**: Highlight key statistics (animals placed, foster families, volunteer hours, placement rates)
          - - **Multi-Channel Engagement**: Dedicated sections for adoptions, fostering, volunteering, and partnerships
            - - **Mobile-First Design**: Fully responsive site that works equally well on phones, tablets, and desktops
              - - **Accessibility First**: WCAG-compliant design with keyboard navigation, screen reader support, and semantic HTML
               
                - ## Site Structure
               
                - ### Pages
               
                - - **index.html** - Home page featuring mission statement, pet finder, impact stats, director's message, and featured adoption story
                  - - **services.html** - Detailed information about adoption process, fostering program, and volunteer opportunities
                    - - **about.html** - Organization history, team, partners, and values
                      - - **contact.html** - Contact form and interest submission for adoptions, fostering, and volunteering

                                                          - ## Getting Started
                                                         
                                                          - ### Prerequisites
                                                          - No build tools or dependencies required. The site runs entirely in the browser.
                                                         
                                                          - ### Installation
                                                          - 1. Clone the repository
                                                            2. 2. Open `index.html` in a web browser
                                                               3. 3. For development, use a local server (e.g., `python -m http.server 8000`) to test local storage and media loading properly
                                                                 
                                                                  4. ### Customization
                                                                 
                                                                  5. #### Update Organization Details
                                                                  6. Edit contact information in:
                                                                  7. - Footer (all pages)
                                                                     - - Contact section in index.html
                                                                       - - Phone numbers and email addresses throughout
                                                                        
                                                                         - #### Customize the Design
                                                                         - All colors, fonts, and spacing are defined as CSS custom properties at the top of `styles.css`:
                                                                        
                                                                         - ```css
                                                                           :root {
                                                                             --color-primary: #0F4C45;        /* Change to your brand primary */
                                                                             --color-accent: #25DAAB;          /* Change to your brand accent */
                                                                             --font-heading: "Poppins", ...;  /* Swap font families */
                                                                             --space-md: 1.25rem;              /* Adjust spacing scale */
                                                                           }
                                                                           ```

                                                                           #### Add or Update Animals
                                                                           Edit the `PETS` array in `js/pet-finder.js`:

                                                                           ```javascript
                                                                           {
                                                                             id: 'unique-id',
                                                                             name: 'Animal Name',
                                                                             species: 'dog', // 'dog', 'cat', or 'small'
                                                                             age: 'adult',   // 'young', 'adult', or 'senior'
                                                                             goodWithKids: true,
                                                                             traits: ['Trait 1', 'Trait 2'],
                                                                             summary: 'Brief description of the animal...'
                                                                           }
                                                                           ```

                                                                           #### Replace Media
                                                                           Update image and video sources in the HTML:
                                                                           - Logo: `media/rescue-logo.png`
                                                                           - - Featured pet: `media/rescue-pet.jpg`
                                                                             - - Director message: `media/rescue-message.mp4`
                                                                               - - Featured story: `media/rescue-feature-*.jpg`
                                                                                
                                                                                 - ## Features Breakdown
                                                                                
                                                                                 - ### Pet Finder
                                                                                 - The interactive pet browser is the heart of the adoption experience:
                                                                                
                                                                                 - **Filtering Options**
                                                                                 - - Species: All animals, Dogs, Cats, Small pets
                                                                                   - - Age: Any age, Under 1 year, Adult, Senior
                                                                                     - - Good with children: Toggle to show only kid-friendly animals
                                                                                      
                                                                                       - **User Interactions**
                                                                                       - - Filters update results instantly
                                                                                         - - Save favorite animals to a persistent shortlist
                                                                                           - - Shortlist persists across browser sessions using localStorage
                                                                                             - - Remove animals from the list anytime
                                                                                               - - Submit inquiry form about saved animals
                                                                                                
                                                                                                 - **Implementation Details**
                                                                                                 - - Data stored in a simple array of objects (production site would use a database API)
                                                                                                   - - Filtering logic is pure JavaScript, no dependencies
                                                                                                     - - Storage uses the browser's localStorage API with a fallback for private browsing

                                                                                                                                                                             - ## Data Management
                                                                                                                                                                            
                                                                                                                                                                             - ### Animal Data
                                                                                                                                                                             - Animals are stored as JavaScript objects in an array. For production deployment, consider:
                                                                                                                                                                             - - Moving to a database (SQLite, PostgreSQL, etc.)
                                                                                                                                                                               - - Creating an API endpoint (`/api/animals`)
                                                                                                                                                                                 - - Building an admin panel for staff to add/update animals
                                                                                                                                                                                   - - Integrating with shelter management software
                                                                                                                                                                                    
                                                                                                                                                                                     - ### Storage & Persistence
                                                                                                                                                                                     - - Saved shortlists use browser `localStorage`
                                                                                                                                                                                       - - Filter preferences saved in localStorage
                                                                                                                                                                                         - - No account system required for basic functionality
                                                                                                                                                                                           - - Data stored locally on the visitor's device
                                                                                                                                                                                            
                                                                                                                                                                                             - ### Scalability
                                                                                                                                                                                             - The current setup works well for organizations with up to a few hundred animals. For larger databases:
                                                                                                                                                                                             - - Implement server-side filtering and search
                                                                                                                                                                                               - - Add pagination or infinite scroll
                                                                                                                                                                                                 - - Consider a database API instead of client-side arrays
